# ⚡ AI Content Repurposer Pro

An enterprise-grade, multi-format AI content repurposing SaaS application built with **Python**, **Streamlit**, and **Groq API** (Llama 3.3). Transform a single piece of text, document, YouTube video, or blog article into high-performing social media content in seconds.

---

## 🚀 Key Features

* **Multi-Source Input:** Paste raw text, upload documents (`PDF`, `DOCX`, `TXT`), or fetch live content directly from YouTube URLs and web blog articles.
* **5+ Output Formats:** Generate Viral Twitter/X Threads, Engaging LinkedIn Posts, Email Newsletters, Executive Bullet Summaries, and Video Scripts.
* **Multi-Language Support:** Generate content in **English**, **Roman Urdu**, and **Urdu**.
* **Custom Brand Tone:** Tailor the output to match your unique brand voice (e.g., *Funny & Sarcastic, Storyteller, Investor Pitch*).
* **Generation History Dashboard:** Track past generations directly from the sidebar with instant download options.
* **Modern SaaS UI:** Clean cards, responsive layouts, and interactive loading states.

---

## 🛠️ Tech Stack

* **Frontend & UI:** Streamlit (Custom CSS SaaS Layout)
* **AI Engine:** Groq API (`llama-3.3-70b-versatile`)
* **Document Parsing:** PyPDF, python-docx
* **Web Scraping & APIs:** YouTube Transcript API, BeautifulSoup4
